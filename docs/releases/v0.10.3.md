# ObsiRead 0.10.3

- **Skip what you do not want to hear.** Settings, Read aloud, Skip. Read aloud now skips sources and references, footnote numbers, web addresses, picture captions, tables and code. Turn each one on or off. Text in brackets can be skipped too.
- **Listen from here.** Press and hold a word, then tap Listen. Reading starts at that sentence.
- **Property sheet has a Done button.** What you type is kept, also when you swipe the sheet away.
- **No doubled properties.** If a template already has a property with that name, the sheet tells you, so the note does not break.
