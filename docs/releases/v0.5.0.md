# ObsiRead 0.5.0

- Listen: tap the headphones in an article. The phone reads it out loud from where you are, and the page follows along. Set the speed in the reading sheet, under Behavior.
- Follow sites: tap +, paste a site address, and tap Follow. New posts show on Home under "New from your feeds". Tap one to read it. Pull down to check for new posts.
- One review across the Obsi apps: when you finish a review, the highlights due in ObsiTube and Obsi Bible come next.
- Set up Obsidian once: if another Obsi app has a vault set up, Settings offers the same vault, folder and tags.
- Settings and the save sheet are now the same in ObsiTube and ObsiRead, so a fix in one reaches both.
