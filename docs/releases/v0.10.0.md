# ObsiRead 0.10.0

- **Natural voices.** Read aloud now uses Microsoft Edge's free natural voices, like Readest. No key and no account. The default is Emma. Your phone's own voices and Google's online voices are still there.
- **Each word lights up as it is read.** The page scrolls with the voice.
- **A player.** A small player sits above the bottom bar. Tap it for the full player: progress, back and next sentence, speed, voice, sleep timer and offline audio.
- **Lock screen and notification controls.** Reading goes on with the screen off. Headphone buttons work.
- **Offline audio.** When you save an article, its audio is saved too, so it plays with no internet. Turn this off, or save only on Wi-Fi, in Settings, Read aloud.
- **Pick your voices.** Voices are grouped by service. Tap a service to see its voices, and tap play to hear one. Set a default voice, and pick whether audio is saved with the default or the last voice used.
- **Settings, Read aloud.** Default voice, speed, offline audio, and what the page does while it reads.

Edge voices need the internet and are not an official Microsoft service, so they can stop working. Saved audio still plays, and the phone's voices always work.
