# ObsiRead 0.3.3

- Saving now asks for every empty field you fill by hand, and for tags. A note saved without them is hard to find later.
- Fixed: a saved note could show up empty in Obsidian. ObsiRead now opens your vault after it saves, not the note itself.
- The message after saving shows where the note went.
- Removed the "Save by itself when I finish an article" switch. It did nothing.
- No more video words: lists, search, highlights and settings all talk about articles now. "Watch later" is now "Read later".
- The insert-data button in each field uses an article icon, not a video icon.
